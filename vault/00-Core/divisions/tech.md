# Tech Division - Content Strategy

## Focus Areas
- Developer tools and productivity
- Open source projects
- Technical tutorials
- Code walkthroughs
- Architecture decisions

## Platform Mix
| Platform | Content Type | Frequency |
|----------|--------------|-----------|
| X | Quick tips, threads | Daily |
| GitHub | README, docs | Weekly |
| Dev.to | Tutorials, deep dives | 2x/week |
| LinkedIn | Professional insights | 3x/week |
| Reddit | Value-first discussions | 2x/week |
| LeetCode | Problem solutions | Weekly |
| HackerNews | Show HN, discussions | As needed |
| Peerlist | Build updates | When shipping |
| Hashnode | Technical articles | Weekly |
| ProductHunt | Launches | Monthly |

## Content Pillars
1. **How I Built This** - Behind-the-scenes of projects
2. **Technical Deep Dives** - Detailed explanations
3. **Tool Comparisons** - Honest reviews
4. **Lessons Learned** - From failures and successes

## Voice Guidelines
- Technical but accessible
- Share code examples
- Be opinionated but back it up
- Acknowledge tradeoffs
