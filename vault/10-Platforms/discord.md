# Discord Platform Rules

## Division: Mafia

## Character Limits
- Message: 2,000 characters

## Golden Rules
1. **Code snippets must use language-specific syntax highlighting (e.g., ```python)**
2. **Must use appropriate role tags (e.g., @devs) ONLY if critical; no spam tagging**

## Message Structure
```
[Context or question]

```python
# Code example with syntax highlighting
def example():
    return "Hello, World!"
```

[Follow-up or request]
```

## Anti-Patterns
- No spam role tags
- No walls of text
- No self-promotion without permission

## Best Practices
- Use appropriate channels
- Format messages for readability
- React to messages appropriately
- Be helpful, not promotional

## Community Building
- Create value before asking for anything
- Share knowledge freely
- Engage in discussions
- Respect community rules
