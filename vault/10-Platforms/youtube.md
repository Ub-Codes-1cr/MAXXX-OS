# YouTube Platform Rules

## Division: Media

## Character Limits
- Title: 100 characters
- Description: 5,000 characters
- Tags: 500 characters total

## Golden Rules
1. **Description must include timestamp links if video > 2 mins**
2. **Must include a clear Channel CTA at the end**

## Description Structure
```
[Hook - first 2 lines]

Timestamps:
0:00 Intro
1:00 [Section 1]
3:00 [Section 2]
5:00 [Section 3]
7:00 Conclusion

Links:
- Website: [URL]
- Twitter: [URL]
- GitHub: [URL]

Subscribe for more: [Channel link]
```

## Anti-Patterns
- No misleading thumbnails
- No clickbait titles
- No missing timestamps

## Best Practices
- Post consistently (1-2x per week)
- Optimize thumbnails (bright colors, faces)
- Add end screens and cards
- Engage with comments in first 24 hours

## SEO Tips
- Use keywords in title and description
- Add tags (but they matter less now)
- Create playlists for related content
- Use closed captions
