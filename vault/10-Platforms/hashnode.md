# Hashnode Platform Rules

## Division: Tech

## Character Limits
- No strict limit, but 800-2,000 words optimal

## Golden Rules
1. **Must include a canonical URL tag if cross-posting from a personal domain**
2. **Must select at least 3 relevant tags from the Hashnode ecosystem**

## Formatting
- Use Markdown with syntax highlighting
- Add cover image (1200x630 recommended)
- Include table of contents for long posts
- Add series tag for multi-part content

## Anti-Patterns
- No duplicate content without canonical
- No excessive tags (max 5)
- No clickbait titles

## Best Practices
- Post consistently (1-2x per week)
- Engage with the Hashnode community
- Use the "Write with AI" feature for drafts
- Cross-post from your personal blog

## SEO Tips
- Use descriptive titles
- Add meta descriptions
- Include internal links
- Optimize for developer keywords
