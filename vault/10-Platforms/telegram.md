# Telegram Platform Rules

## Division: Media

## Character Limits
- Message: 4,096 characters
- Caption: 1,024 characters

## Golden Rules
1. **Must use Markdown formatting for bolding key insights**
2. **Must include direct, un-shortened links for trust**

## Message Structure
```
**[Key insight or headline]**

[Value or explanation]

[Link to resource]

---
[Channel name]
```

## Markdown Formatting
- **Bold** for key insights
- *Italic* for emphasis
- `Code` for technical terms
- [Link text](URL) for links
- > Quote for citations

## Anti-Patterns
- No shortened URLs
- No excessive emojis
- No spam posting

## Best Practices
- Post consistently
- Use channels for broadcasts
- Use groups for discussion
- Pin important messages

## Growth Tips
- Share valuable content
- Cross-promote on other platforms
- Engage with subscribers
- Use Telegram bots for automation
