# ProductHunt Platform Rules

## Division: SaaS

## Character Limits
- Tagline: 60 characters
- Description: 260 characters
- Maker's Note: No strict limit

## Golden Rules
1. **Pitch must be under 100 words. Must include "Maker's note" perspective**
2. **Must explicitly ask for specific feedback, not just "upvotes"**

## Launch Structure
```
**Tagline:** [One line value proposition]

**Description:** [What it does, who it's for]

**Maker's Note:** [Why you built this, what you learned]

**Seeking Feedback:** [Specific question for the community]
```

## Anti-Patterns
- No "please upvote" requests
- No generic descriptions
- No missing maker's note

## Best Practices
- Launch Tuesday-Thursday
- Engage with every comment
- Share on social media before launch
- Prepare a launch day checklist

## Launch Checklist
- [ ] Product page optimized
- [ ] Social media posts scheduled
- [ ] Email list notified
- [ ] Team ready to engage
- [ ] Analytics tracking set up
