# Dev.to Platform Rules

## Division: Tech

## Character Limits
- No strict limit, but 800-1,500 words optimal

## Golden Rules
1. **Must contain at least one H2 (##) and one H3 (###) heading**
2. **Must include at least one code block if technical**

## Formatting
- Use series tags for multi-part posts
- Add cover image (1000x500 recommended)
- Use code blocks with language specification
- Add TL;DR at the top for long posts

## Anti-Patterns
- No clickbait titles
- No copy-pasted content without attribution
- No self-promotion spam

## Best Practices
- Post Tuesday-Thursday
- Engage with comments within 24 hours
- Cross-post from personal blog with canonical URL
- Use relevant tags (max 4)

## Content Types That Work
- Tutorials and how-tos
- Project retrospectives
- Tool comparisons
- Debugging stories
