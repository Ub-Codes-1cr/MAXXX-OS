# GitHub Platform Rules

## Division: Tech

## Content Types
- README files
- Repository descriptions
- Commit messages
- Issue templates

## Golden Rules
1. **Must be valid Markdown with proper headings**
2. **All code snippets must be wrapped in ``` blocks**
3. **README must include Installation and Usage sections**

## README Structure
```markdown
# Project Name

Brief description (1-2 sentences)

## Features
- Feature 1
- Feature 2

## Installation
Step-by-step guide

## Usage
How to use the project

## Contributing
Guidelines for contributors

## License
License information
```

## Anti-Patterns
- No vague descriptions
- No missing installation steps
- No uncommented code

## Best Practices
- Use semantic commit messages
- Add badges for build status, coverage
- Include screenshots/GIFs for visual projects
