# Peerlist Platform Rules

## Division: Tech

## Character Limits
- Max: 400 characters

## Golden Rules
1. **Focus strictly on "what I built" and "tech stack"**
2. **Must tag specific tools/frameworks used**

## Formatting
- Start with what you built
- List the tech stack with tags
- Add a screenshot or GIF
- Include a link to try it

## Anti-Patterns
- No personal stories
- No company updates
- No job announcements

## Best Practices
- Post when you ship something
- Keep it concise and technical
- Tag the technologies you used
- Share metrics if possible

## Content Structure
```
What I built: [Project name]
Tech stack: [Tagged technologies]
What it does: [One sentence]
Link: [URL]
```
