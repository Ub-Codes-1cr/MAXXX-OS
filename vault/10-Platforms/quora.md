# Quora Platform Rules

## Division: Media

## Character Limits
- Answer: No strict limit, but 300+ words optimal

## Golden Rules
1. **Answer must be >300 words and cite at least one authoritative source**
2. **Must directly answer the question in the very first sentence**

## Answer Structure
```
[Direct answer - first sentence]

[Elaboration - 2-3 paragraphs]

[Example or evidence]

[Source citation]

[Conclusion with takeaway]
```

## Anti-Patterns
- No "It depends" openers
- No unsourced claims
- No affiliate links

## Best Practices
- Answer questions in your expertise
- Add credentials to your profile
- Include personal experiences
- Upvote other good answers

## Authority Building
- Answer consistently in one topic
- Get Space contributor status
- Link to your published work
- Build a following
