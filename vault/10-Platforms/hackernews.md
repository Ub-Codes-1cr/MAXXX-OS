# HackerNews Platform Rules

## Division: Tech

## Character Limits
- Title: 80 characters recommended
- Body: No strict limit

## Golden Rules
1. **Title must be plain text, no clickbait, no exclamation marks**
2. **Show HN posts must include a direct, working link to the project**

## Title Formats
- "Show HN: [Project Name] - [One line description]"
- "Ask HN: [Question]"
- "[Technical Topic]"

## Formatting
- Start with the most important information
- Include a working demo or repo link
- Add technical details (stack, architecture)
- Be transparent about limitations

## Anti-Patterns
- No marketing language
- No "revolutionary" or "game-changing"
- No missing links to the actual project

## Best Practices
- Post Tuesday-Thursday, 10am-2pm EST
- Respond to comments quickly
- Be honest about limitations
- Thank people for feedback

## Algorithm Notes
- First 2 hours determine front page
- Comments boost ranking
- Upvotes from accounts with karma matter more
